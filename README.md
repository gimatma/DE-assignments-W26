# Differential Equations - Assignments 
This repository contains assignments designed for **MATH2121: Differential Equations** and Mount Allison University, used during the Winter 2026 term. 

## Goals and Methodology
The goal of these assignments is to help students gain hands-on experience with computational tools, in particular, Python libraries like NumPy and SymPy for numerical and symbolic calculations, respectively. 

Activities are carefully scaffolded to accommodate for the different levels of programming experience, with instructions guiding the students from basic implementation to open-ended analysis.  

The Jupyter Notebooks are configured to run in a web browser through *MyBinder*, eliminating the need for software installation.
